## 観察事項

(a) **check_compressions の該当は、すべて否定文か資料の中の語に対するもの**だった。モデルは返った関連原文と見比べ、
　　読みを変えずに保持した。該当したパターン：P30（R01-en-guards）・P01（R14 の3本）・P02（R14-none・R14-guards）・
　　P04（R13-guards）・P22（E02-none）・P54（R08-en-guards・9/19）。道具が「要確認箇所と原文を返し、判定はしない」ことが
　　意図どおり働いた。9/19 の8本で check_compressions を使ったのはガード条件の3本で、該当は R08-en-guards の1件だけ（(h)）。

(b) **取りこぼし**：R01 の「AIでは代替できない…（と）証明している」は日英とも該当0件、R08 の「障害を残す」も0件だった。
　　どちらも読みの失敗の典型として台帳が挙げている語で、登録語形に無かった → **PATTERNS-0.2.0** で追加。

(c) **強調記号を外した引用が `quote_not_found`**：原文の `**…**`・`*…*` を外して引用すると一致しない
　　（R14 の ja・en で計7回・著者集計）。モデルは記号つきで引き直して照合した → **NORM-1.1.0** で強調記号を正規化の対象に。

(d) **「ablation」が「domain-ablation」に当たらない**（R13）。ハイフンが語の一部として扱われるため
　　→ **SEARCH-1.1.0** でハイフンを語境界としても扱う（ハイフン付きの語句そのものも従来どおり当たる）。

(e) **「specification cost」の上位20件はすべて T1** で、T2 の記述にはガイド経由でたどり着いた（R14）。
　　順位の規則（種類数→直接一致→総出現数→論文順→行番号）どおりの結果で、読みは保たれた。記録として残す。

(f) **T1 §3.1 L115 と §4.2 L191／表2 の記述の食い違い**を、二つのセッション（R13-none・R13-guards）が独立に検出した。
　　原文の記述の問題で Reader の不具合ではない。原文は改変しない。**著者の在庫**として預ける。

(g) **Code タブでは、prompts の一覧が一度サーバに触れてから現れる**（最初のツール呼び出しより前は一覧が空に見える）。
　　クライアント側の表示の挙動。README の「接続時に知っておくこと」に一行足した。

(h) **改版の実地での作動**（9/19 の8本）。
　　**NORM-1.1.0**：R14-en-none の `verify_quote` 4回のうち2回が、強調記号を外した引用のまま `normalized`（MARK-EMPH）で一致した
　　（T1 §2.1 L54 の `**`、T2 §2.1 L37 の `*`）。4回とも `ok` で、引き直しは無い。(c) で `quote_not_found` になっていた型の引用が、
　　改版後はそのまま通った。
　　**P54**：R08-en-guards の `check_compressions` が、要約の下書きの「keep obstacles」に P54（PATTERNS-0.2.1）で該当し、
　　関連原文として T5 §4.6 の脚注（L193・1154〜1352字）を返した。下書きは否定文（does not tell anyone to keep obstacles）で、
　　モデルは関連原文と見比べて言い回しを保持した。(b) で取りこぼした型の語に、改版後は該当が出た。

(i) **T3 の要旨と §5 の、層一の言い回しの差**（R15-en-none が注記）。要旨（L11）は二層の処方を
　　「… AI guardrails for what can be distributed; protected second-personal exchange for what cannot」と書き、
　　§5（L120）は層一を「everything the decomposition can place」と定義する。方向の是認（endorsement）は任せられない
　　（分配できない）が分解の中には置かれるので、要旨の言い方では層二に、§5 の定義では層一に入るように読める。
　　セッションは §5 の定義に従って層一とし、層を分けるのは「任せられるか」ではなく「成分か関係か」だと注記した。
　　要旨の句が三つの処方すべてに掛かるのか、AI guardrails だけに掛かるのかで、差の有無が変わる。
　　原文の言い回しの話で Reader の不具合ではない。原文は改変しない。**著者の在庫**として預ける。
