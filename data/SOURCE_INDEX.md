# Source and Section Index

This is a navigation aid, not an additional theory. Repository version 3.5.0; paper versions remain separate. For a narrow question, use a relevant section rather than loading the entire corpus. For the whole programme, read T1 → T5.

## Source precedence and scope

1. The paper DOI is the canonical scholarly citation target.
2. The reproduced paper text is the local source to check; the supplied T1–T4 blocks are unchanged.
3. Theory Map, claim ledger, and application guidance are derivative interpretations.
4. If a guide and the paper disagree, report it. Do not silently reconcile them.

Author–date suffixes and notes are local to each paper. `Tomita 2026a` is not a corpus-wide identifier. Paper T4 is Japanese with an English abstract; the separate English access translation below is a reading aid. Read the Japanese text to resolve wording disputes. Figures omitted in the supplied corpus remain omitted.
